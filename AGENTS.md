# Tenmaku Project Instructions

- Read both `docs/SPEC.md` and `docs/IMPLEMENTATION.md` before starting work. The specification defines requirements and acceptance criteria. The implementation guide records the assumptions and sequence.
- Follow the specification's rules for independent implementation. Follow the procedure under “Accepted Materials” before consulting or adopting any existing app implementation, third-party code or assets, or Apple sample code.
- `verification/` contains past investigation records and is excluded from Git. Keep it out of the implementation inputs. Use only `docs/VERIFICATION.md` and `docs/VERIFICATION_SUMMARY.md` as verification evidence.
- Get the user's confirmation before running any test that darkens or covers the physical displays.
